# Screenshot placeholders

This directory is reserved for genuine screenshots captured from a locally running application. No screenshots are included yet; do not treat these filenames as existing images.

Suggested captures:

- `01-home.png` — welcome screen and suggested questions.
- `02-chat-citations.png` — conversation showing verified PDF references.
- `03-image-search.png` — an explicit image-search request and returned gallery.
- `04-dark-mode.png` — the interface in dark theme.

Before publishing, inspect each capture for API keys, private paths, personal data, terminal windows, and other local secrets. Use representative data you are authorized to publish.
